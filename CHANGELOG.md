# Changelog

## 0.1.0

First public release.

- `Topic+` folders become numbered subfolders of plain-language notes, researched with the Anthropic API.
- `paper+.pdf` files become a five-point overview with page references, each key point researched on its own.
- Folder context: parent and sibling folders shape the topic, so `c#/intro+` is researched as "Introduction to C#".
- Subject-specific sections (code, formulas, timelines, vocabulary) and separate Questions and Answers files.
- Explorer icons for working, ready, done and failed; a review pop-up with select all, add your own folder, reordering and re-suggest.
- Real sources listed at the end of each note.
- Undo last research, using the system trash.
- Model picker that greys out models without PDF or web search support.
